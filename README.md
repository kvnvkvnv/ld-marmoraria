# Stone Legacy Elevated

Crie uma NOVA VERSÃO COMPLETA, PREMIUM E ULTRAMODERNA do site da LD MARMORARIA.

SITE ATUAL PARA REFERÊNCIA:
https://ldmarmoraria.com.br/

IMPORTANTE:
Não quero apenas uma cópia ou pequena reformulação do site atual. Quero uma transformação completa da experiência visual e da interface, mantendo a identidade e as informações verdadeiras da empresa, mas elevando o projeto para um nível de site de arquitetura/marmoraria de alto padrão.

A empresa trabalha com mármores, granitos, materiais importados e pedras decorativas. A LD Marmoraria nasceu em São José dos Campos em 2008 e atualmente está localizada em Jacareí.

OBJETIVO PRINCIPAL:
Fazer o visitante perceber imediatamente que a LD Marmoraria trabalha com projetos sofisticados, acabamento de qualidade e materiais nobres.

O site precisa transmitir:

* Luxo
* Sofisticação
* Arquitetura
* Precisão
* Exclusividade
* Confiança
* Modernidade
* Qualidade artesanal
* Tecnologia
* Atendimento personalizado

A sensação deve ser semelhante à de sites premium de arquitetura, interiores e marcas de materiais de luxo.

==================================================
DIREÇÃO VISUAL
==============

Criar uma identidade visual elegante e minimalista.

Paleta principal:

* Preto quase absoluto
* Off-white / marfim
* Cinza pedra
* Tons quentes de areia
* Pequenos detalhes metálicos discretos

Não exagerar no dourado.

Tipografia:
Usar uma combinação de:

* Fonte serifada sofisticada para títulos
* Fonte sans-serif moderna para textos e interface

Os títulos devem ter bastante personalidade.

Layout:

* Muito espaço negativo
* Imagens grandes
* Tipografia editorial
* Cards sofisticados
* Bordas extremamente discretas
* Sombras suaves
* Cantos levemente arredondados, sem exagero
* Grid inspirado em arquitetura/editorial
* Seções assimétricas
* Muito contraste entre fotografia e tipografia

Evitar:

* aparência de template genérico
* excesso de cards
* gradientes exagerados
* neon
* visual gamer
* excesso de animações
* excesso de elementos na tela
* aparência de site de empresa pequena genérico
